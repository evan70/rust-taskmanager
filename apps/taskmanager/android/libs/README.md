# Bundled library: Shizuku API 13.1.5

The four jars here are the classes of Shizuku's client library (`dev.rikka.shizuku:api`, `provider`,
`aidl` and `shared`, version 13.1.5), taken unchanged from Maven Central
(https://repo1.maven.org/maven2/dev/rikka/shizuku/). Their SHA-1 checksums matched the ones Maven
Central publishes for the `.aar` files they were unpacked from. The library is licensed under the
MIT License, copyright 2021 RikkaW (https://github.com/RikkaApps/Shizuku-API); the licence text is in
`LICENSE-shizuku-api.txt` next to the jars.

They let the app use Shizuku, if the person has it installed and running, as an alternative way to
start the helper. The app works without them being used.
